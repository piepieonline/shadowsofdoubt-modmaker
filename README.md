# Shadows of Doubt — Mod Maker

An extensible browser-based mod editor for Shadows of Doubt. Merges the previously separate
[CaseEditor](https://github.com/piepieonline/ShadowsOfDoubt-CaseEditor) and
[DDSViewer](https://github.com/piepieonline/ShadowsOfDoubt-DDSViewer) into one app, with a flow-plugin
architecture so new mod types can be added without forking the tool again.

## Status

Mid-migration. See `.local/PLAN.md` for the phased plan.

Currently at **Phase 0** — both apps have been imported with their history intact and live side by side,
unmodified, under `flows/`. They do not share code yet.

| Flow | Path | Origin |
|---|---|---|
| ScriptableObject / Case editing | `flows/scriptableObject/` | ShadowsOfDoubt-CaseEditor |
| DDS text content | `flows/dds/` | ShadowsOfDoubt-DDSViewer |

## Running locally

The File System Access API (`showDirectoryPicker`) requires a secure context, so this must be served over
HTTPS — opening `index.html` from disk will not work.

```sh
http-server -c-1 -S
```

That needs `cert.pem` and `key.pem` in the repo root (both gitignored). Generate them with:

```sh
openssl req -x509 -newkey rsa:2048 -nodes -keyout key.pem -out cert.pem -days 365 -subj "/CN=localhost"
```

Then open `https://localhost:8080/flows/dds/` or `https://localhost:8080/flows/scriptableObject/`.

Requires a Chromium-based browser — Firefox and Safari do not implement the File System Access API.
